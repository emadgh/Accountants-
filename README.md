# Accountants Web — حسابداری تک‌صفحه‌ای

برنامه حسابداری فارسی و RTL برای مدیریت طرف‌حساب‌ها، کالا و خدمات، فاکتور، انبار، دریافت و پرداخت، چک و گزارش‌ها.

## اجرا در توسعه

نیازمندی: Node.js نسخه 22.13 یا 24 و npm.

```bash
npm install
npm run dev
```

سپس برنامه را از `http://localhost:3000` یا `http://127.0.0.1:3000` باز کنید. مسیر API دیتابیس فقط درخواست‌های محلی را می‌پذیرد؛ نشانی شبکه مثل `http://192.168.x.x:3000` پشتیبانی نمی‌شود.

## پایگاه داده

داده‌های برنامه در فایل SQLite به مسیر `data/accountants.sqlite3` ذخیره می‌شوند. فایل هنگام اولین درخواست دیتابیس ساخته می‌شود. سرور از SQLite داخلی Node.js (`node:sqlite`) استفاده می‌کند و محل فایل در `lib/persistence/server-database.ts` تنظیم شده است؛ متغیر `DATABASE_URL` لازم نیست.

رمز عبور به‌صورت hash ذخیره می‌شود. فقط شناسه نشست در `sessionStorage` مرورگر می‌ماند. برای پشتیبان‌گیری و بازیابی اطلاعات، از بخش «تنظیمات → پشتیبان‌گیری» استفاده کنید.

## دستورات

```bash
npm run dev        # اجرای توسعه
npm run typecheck  # بررسی TypeScript
npm run build      # ساخت نسخه تولید
```

جزئیات مسیر توسعه در [ROADMAP.md](./ROADMAP.md) نگهداری می‌شود.
