# Accountants Web — حسابداری تک‌صفحه‌ای

برنامه حسابداری فارسی و RTL برای مدیریت طرف‌حساب‌ها، کالا و خدمات، فاکتور، انبار، دریافت و پرداخت، چک و گزارش‌ها.

## اجرا در توسعه

نیازمندی: Node.js نسخه 22.13 یا 24 و npm.

```bash
npm install
npm run dev
```

سپس برنامه را از `http://localhost:3000` یا `http://127.0.0.1:3000` باز کنید. برای ورود از دستگاه دیگر باید برنامه روی سرور روشن باشد و HTTPS را از طریق reverse proxy تنظیم کنید؛ جزئیات در [راهنمای استقرار](./DEPLOYMENT.md) آمده است. هنگام خاموش‌بودن سرور، ساخت و ذخیره سند ممکن نیست.

## پایگاه داده

داده‌های برنامه در فایل SQLite در مسیر `data/accountants.sqlite3` و فایل‌های پروژه در پوشه `data/attachments` ذخیره می‌شوند. مسیر پیش‌فرض کنار کد است؛ برای استقرار، `ACCOUNTING_DATA_DIR` را به دیسک پایدار و بیرون از پوشه `public` تنظیم کنید. فایل‌ها هنگام اولین درخواست دیتابیس ساخته می‌شوند. سرور از SQLite داخلی Node.js (`node:sqlite`) استفاده می‌کند و `DATABASE_URL` لازم نیست.

رمز عبور به‌صورت hash ذخیره می‌شود. فقط شناسه نشست در `sessionStorage` مرورگر می‌ماند. برای پشتیبان‌گیری و بازیابی اطلاعات، از بخش «تنظیمات → پشتیبان‌گیری» استفاده کنید.

## دستورات

```bash
npm run dev        # اجرای توسعه
npm run typecheck  # بررسی TypeScript
npm test           # آزمون‌های جریان حسابداری و API
npm run build      # ساخت نسخه تولید
npm start          # اجرای نسخه تولید؛ پس از build
```

جزئیات مسیر توسعه در [ROADMAP.md](./ROADMAP.md) نگهداری می‌شود.
