# Accountants Web — حسابداری تک‌صفحه‌ای

یک برنامه حسابداری فارسی و RTL بر پایه Next.js و React برای مدیریت مشتریان، کالا و خدمات، فاکتور فروش و خرید، انبار، دریافت و پرداخت، چک و سررسید.

## ویژگی‌ها

- Next.js App Router + React + TypeScript
- UI مبتنی بر الگوی shadcn/ui و Radix Dialog
- افکت‌های سبک ReactBits-style برای داشبورد
- کاملاً RTL و مناسب فارسی
- ویرایش فاکتور در همان فرم چاپی (WYSIWYG)
- «ثبت نهایی و چاپ» همان فاکتور را قطعی کرده و نسخه A4 رسمی چاپ می‌کند
- اطلاعات فروشنده، آدرس، شماره تماس، کارت، شبا و پاورقی مستقیماً از داخل فاکتور قابل ویرایش‌اند
- مشتری / تامین‌کننده با شناسه ملی، کد اقتصادی و کدپستی
- کالا و خدمت، قیمت خرید و فروش، موجودی و حداقل موجودی
- اثر خودکار فاکتورهای قطعی خرید/فروش روی موجودی
- تسویه نقدی، کارت و چک و محاسبه خودکار وضعیت تسویه فاکتور
- مدیریت چک‌های دریافتی/پرداختی و سررسید
- گزارش خلاصه فروش، خرید، موجودی و چک‌ها
- ذخیره تمام داده‌ها در LocalStorage مرورگر
- خروجی و بازیابی JSON برای نسخه پشتیبان
- بدون بک‌اند و قابل خروجی‌گیری Static با `next build`

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## بیلد نهایی

```bash
npm run build
```

به دلیل `output: 'export'` خروجی استاتیک در پوشه `out` ساخته می‌شود.

## نکته داده‌ها

داده‌ها در کلید `accountants-web-v1` داخل LocalStorage ذخیره می‌شوند. برای انتقال داده‌ها به مرورگر یا سیستم دیگر، از بخش «تنظیمات → پشتیبان‌گیری» خروجی JSON بگیرید.
